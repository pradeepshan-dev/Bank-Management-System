# 🏦 Bank Management System

A console-based **Bank Management System built with Python and Object-Oriented Programming (OOP)**.

This project simulates basic banking operations such as account creation, deposits, withdrawals, balance checking, account management, and money transfers.

## ✨ Features

- 🏦 Create a new bank account
- 🔍 Search for an account
- 💰 Deposit money
- 💸 Withdraw money
- 💳 Check account balance
- 🗑️ Delete an account
- 👥 Display all accounts
- ✏️ Update account name or PIN
- 🔄 Transfer money between accounts
- 🔐 4-digit PIN verification
- ⚠️ Input validation and error handling
- 🚫 Duplicate account number checking
- 💵 Balance validation for transactions

## 🛠️ Technologies Used

- **Python**
- **Object-Oriented Programming (OOP)**
- Classes and Objects
- Lists
- Conditional Statements
- Loops
- Exception Handling
- User Input

## 🧠 OOP Structure

The project uses two main classes:

### `Account`

Responsible for storing individual account information such as:

- Account number
- Account holder name
- Balance
- Secret PIN

It also contains methods for basic account operations.

### `Bank`

Responsible for managing multiple `Account` objects.

It handles:

- Account creation
- Account searching
- Deposits
- Withdrawals
- Account deletion
- Account updates
- Money transfers
- Displaying accounts
